# 接入 Slack

[English](../../platforms/slack.md) · 简体中文

SintBot 以你自己创建的应用加入 Slack 工作区，通过 Socket Mode 连接：任务在你的 Mac 上执行，不需要公网地址，免费工作区也能用。私聊机器人，或在频道里 @它。

Slack 没有扫码建应用这一步，所以接入是三小步：用已经填好的链接创建应用、粘贴两枚令牌、给机器人发一句话。全程不用开终端。

## 开始之前

- 你需要有在工作区安装应用的权限。工作区要求管理员审批时，请管理员处理，或者自己新建一个免费工作区。
- 一个 Slack 应用只给一台 Mac 用。Slack 把每条消息只交给应用的其中一条连接，两台 Mac 共用一个应用会各自漏消息。第二台 Mac 请另建一个应用。

## 1. 创建应用

首次打开时，选好项目和执行器，在「聊天平台」里选 **Slack**，点「在 Slack 创建应用」。已经在用的安装，改到控制台「设置 → Slack」里操作，现有连接、项目和历史都保留。

Slack 打开时，应用的权限和事件已经填好。选择工作区，点 **Next**，再点 **Create**。应用名称可以在点之前先在 SintBot 页面上改。

按钮下面的「声明为 Slack Agent」默认不勾，一般保持不勾。勾上以后，频道线程里会出现 Slack 原生的「Working…」状态和 Stop 按钮；但 Slack 规定，声明为 Agent 的应用不能给工作区访客使用，和它的私信也都会变成线程，这两点以后都撤销不了。不勾也照常使用：任务进行中照样有 ⏳ / ✅，停止任务用 `!stop`（见「日常使用」）。用 SintBot 1.4.24 创建的应用已经声明为 Agent，这些效果已经生效，不用另做处理。

## 2. 粘贴应用级令牌

创建后停在应用的 **Basic Information** 页。往下找到 **App-Level Tokens**，点 **Generate Token and Scopes**，名称随意，权限选 `connections:write`，点 **Generate**。复制 `xapp-` 开头的令牌，粘贴到 SintBot。Slack 的应用设置页第一次打开可能要等十几秒，一直空白就刷新一次。

粘贴后 SintBot 立即验证；贴成了别的令牌会直接告诉你贴的是什么。

## 3. 安装应用并粘贴 Bot Token

在 SintBot 里点「打开安装页」，在 Slack 里点带工作区名的安装按钮（例如 **Install to Acme**），再点 **Allow**（中文界面是「允许」）。复制 `xoxb-` 开头的 **Bot User OAuth Token**，粘贴到 SintBot。

点「连接 Slack」（控制台里是「连接并绑定项目」）。SintBot 会核对两枚令牌属于同一个应用，并且应用具备需要的权限。

两枚令牌只保存在这台 Mac 上、只有你的账号能读的配置文件里。不要把它们发到聊天里。

### 经代理访问 Slack

这台 Mac 要经代理才能访问 Slack 时（例如中国大陆网络），在 Slack 步骤的「代理」里填写 `http://` 开头的代理地址，例如 `http://127.0.0.1:7890`。打开接入页的终端里设置了代理时，这里会自动填上，可以改，也可以清空；带用户名和密码的代理只显示成 `***`。两枚令牌的验证和之后的连接都走这里填的代理。它会随连接保存为 SintBot 服务的网络代理，不只用于 Slack：其他聊天平台和这台 Mac 上的模型工具也经它访问网络，飞书、企业微信和本机地址会一起记为直连。服务以后由系统或桌面 App 启动、没有终端里的代理设置时也照样使用。接入完成后紧接着启动的服务同样按这一栏的选择走，即使终端里设置的是别的代理，或者你清空了这一栏。只支持 http 代理，主机要写 IP 地址或英文域名：中文域名、全角的点和数字都不收。

在控制台「设置 → Slack」添加时，用的是服务启动时的代理，卡片上显示的就是服务实际在用的那个（启动服务的终端里设置的代理优先于配置里保存的）。这个代理来自终端、配置里还没有时，卡片上会出现「把服务正在用的代理一起保存」，默认勾选；保存后它同样是整个服务的网络代理。

## 4. 发第一句话

SintBot 显示「等待你的消息」时，点「在 Slack 里打开机器人」，给它发任意一句话。这个会话就绑定到你选的项目，机器人会回复已连接项目。

想绑定频道：先用 `/invite @机器人名` 把它请进频道，再在频道里 @它。机器人不在的频道收不到任何消息；私有频道里没有机器人时，Slack 还会报「找不到频道」。第一句只用于绑定，收到回复后再发任务。

可以先试这个任务：「读取项目 README 的第一行，只回复这一行。」

## 再绑一个频道

每个会话绑定一个项目目录。再绑一个频道：先 `/invite @机器人名` 把它请进频道，再到控制台「群 · 项目 → 配置群项目」，选 Slack 并选中这个频道。这里只列出机器人已加入的频道；手填的频道 ID 若机器人还不在里面，控制台会提示先邀请它。

## 日常使用

- **私聊：** 每条消息都是任务，答案直接回在会话里。
- **频道：** 只有 @机器人 的消息才是任务，答案回在你那条消息的线程里；要继续追问，在线程里再 @它。
- **命令以 `!` 开头。** Slack 把 `/` 留给它自己的斜杠命令，所以请输入 `!status`、`!stop`、`!skip`、`!new`、`!model`、`!help`；在频道里发命令同样要 @机器人。线程之外也可以用斜杠命令 `/sint stop` 等。
- **任务进行中**，你的消息上会有 ⏳，答案送达后变成 ✅。
- **停止任务**：在哪说停，就停哪。在任务的线程里 @机器人发 `!stop`，只停这个线程正在跑的任务，排队的任务照常处理（同一线程里排着的补充也一样；要取消排队中的消息，删除它）；这个线程没有任务在跑时，只会提示一句，什么也不停。要停整个频道（当前任务和所有排队的），在频道里另发一条消息 @机器人 `!stop`，或者用 `/sint stop`。私信里发 `!stop`，停止当前任务并取消所有排队的。声明为 Slack Agent 的应用，频道线程里还有原生的停止（Stop）按钮：效果和在这个线程里发 `!stop` 一样；任务结束后再点，只会提示这一轮已经结束。
- **没能完成的任务**（比如服务中途被停掉）会把 ⏳ 换成 ⚠️，线程里会说这条没有完成。SintBot 不会自己重跑；还需要的话请重发。
- **图片和文件**随任务一起发，会保存到你的 Mac 并交给任务。超过 30 MB 的文件不下载。
- **删除你发的消息**等于取消：排队中的消息会被丢弃，正在执行的任务会停止。
- **很长的答案**会分成连续的几条消息。
- **任务进行中再发消息。** 在频道里，每个线程是一件独立的任务。在正在执行的任务的线程里再发（同样要 @它），模型读到后补进当前任务，这条消息也会挂上 ⏳，答案回在这个线程里。在这个线程之外另起的 @ 会作为单独的任务排队：它的线程里会提示「已排队」，答案回在它自己的线程里。同一线程里排队的几条会一起处理。最多排两条；再多，或任务正在收尾时，会请你稍后重发。私聊里，再发的消息补进当前任务。想让所有消息都排队而不补进，在控制台把这个项目的「忙时跟进」关掉。`!skip` 跳过当前任务，接着处理排队的。
- **群内提示语言。** 每个会话各有一项设置，中文或英文，决定 SintBot 自己在这个会话里说的话用哪种语言：提示、命令回复、状态和报错。它不改模型的回答。Slack 会话默认用英文，与接入页或控制台的界面语言无关。要改成中文或改回英文：在控制台「群 · 项目」里打开这个会话的卡片，展开「更多设置」，选「群内提示语言」。从下一条消息起生效，任务进行中也可以改，对话照常继续。

保持 Mac 不休眠、SintBot 服务在运行。关闭窗口不会停止服务。

## 暂未提供

- 任务把文件或图片发进 Slack。答案里会写明文件在项目里的路径。
- 任务进行中的文字进度。你能看到状态和最终答案。
- 画布和读取频道历史。

## 排查

| 现象 | 处理 |
|---|---|
| 提示「你贴的是 Bot Token」或别的令牌 | 两枚令牌各贴各的框：先 `xapp-`，后 `xoxb-`。 |
| 应用级令牌被拒绝 | 在 **Basic Information → App-Level Tokens** 重新生成一枚，权限选 `connections:write`。 |
| 提示「两枚令牌来自不同的 Slack 应用」 | 两枚令牌都从同一个应用的设置页复制。 |
| 提示「连不上 Slack」 | 检查网络。这台 Mac 要经代理访问 Slack 时（例如中国大陆网络），在接入页 Slack 步骤的「代理」里填上地址再试。已经在用的安装，在配置里设置 `proxy`（如 `{"https": "http://127.0.0.1:7890"}`）后重启服务，验证和连接都会走它。 |
| 提示应用缺少权限 | 用链接重新创建应用，或在应用的 **App Manifest** 页补上权限后点 **Reinstall to Workspace**。 |
| 等待消息超时 | 给机器人发一条私聊，或先把它请进频道再 @它，然后重试。 |
| 机器人在频道里不回话 | 要 @它，并确认已经用 `/invite @机器人名` 请进频道。 |
| 绑定频道后提示机器人还不在频道里，或者回复时报「找不到频道」 | 在这个频道里发 `/invite @机器人名`。私有频道里没有机器人时 Slack 显示为找不到频道；重装应用后机器人会离开原来的频道，要重新邀请。 |
| 控制台显示 Slack 连接失败 | 令牌被撤销或应用被移除（最多约 5 分钟后显示），用新令牌重新接入。 |
| Slack 连接标黄：「可能有另一台机器在用同一个 Slack 应用」 | 另一台 Mac（或另一个 SintBot）也连着这个应用，Slack 每条消息只交给其中一台。到那台停掉它，或给那台 Mac 另建一个应用。提示在约 15 分钟内自动消失。 |

## 手动创建应用

链接打不开时，到 [api.slack.com/apps](https://api.slack.com/apps) 选择 **Create New App → From a manifest**，选工作区并粘贴 [`slack-app-manifest.yaml`](../../slack-app-manifest.yaml)，然后从第 2 步继续。这份清单默认不声明 Slack Agent；确实要声明的话，按文件开头的说明去掉三行前面的 `# `（效果和不可撤销的部分见第 1 步）。

不要给应用打开令牌轮换：它是单向开关，打开后关不掉，Bot Token 会每 12 小时过期。

适配器的机制和背后的 Slack 平台事实见 [SLACK.md](../SLACK.md)。
