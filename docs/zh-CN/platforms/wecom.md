# 接入企业微信

[English](../../platforms/wecom.md) · 简体中文

使用企业微信「智能机器人 → API 模式 → 长连接」，任务在你的 Mac 上执行，无需公网回调地址。普通群 webhook 机器人不能用于接收任务。

开始前，手机需已安装企业微信，并加入或创建了一个企业（创建免费、无需认证）。不需要建群：个人组织只有自己一个人，也可以直接和机器人单聊。

## 1. 扫码创建机器人

首次打开 App：填写项目，在「聊天平台」选择「企业微信」，点击「扫码创建机器人」，用手机企业微信扫码确认。机器人自动创建，默认名为「\<你的名字\>的机器人」；Bot ID 和 Secret 自动保存在这台 Mac，不用复制。

已经在用飞书或本机对话：进入控制台「设置 → 企业微信」，选好项目目录和执行器，点「扫码创建机器人」，流程相同；接入后卡片显示连接状态和已绑定项目，Bot ID 在「高级」里。原飞书连接、项目和历史保留。

同一个机器人只由一台 SintBot 实例连接。测试时使用独立机器人，避免挤掉已有连接。凭据只在本机保存，不要发到群里。

### 已有机器人

展开「已有机器人？手动填写 Bot ID 和 Secret」，填写已有机器人的凭据。需要手动创建时，可从以下任一入口进入，选择「API 模式创建」，连接方式选「使用长连接」：

- 企业微信电脑端：「工作台 → 智能机器人 → 创建机器人 → 手动创建」。
- 管理后台 work.weixin.qq.com：「安全与管理 → 管理工具 → 智能机器人」。

企业的创建权限由管理员设置；没有入口时先核对客户端版本和组织权限。手动填写后，同样按第 2 步给机器人发一句话完成接入。

## 2. 发一句话完成接入

**10 分钟内**在企业微信里给机器人发一句话：单聊直接发；在群里先把它拉进群，再 @它。找机器人时，可在企业微信顶部搜索它的名字，或进入「工作台 → 智能机器人」。

机器人回复「已连接项目 …」后即完成接入，之后就能直接发任务，例如「读取 README 第一行，只回复这一行」。

保持 Mac 在线和 SintBot 服务运行。关闭窗口与停止后台服务是不同操作。

## 日常使用

- 单聊里直接发任务，不用 @；群里每次任务或命令都要 @机器人，「@所有人」不会触发机器人。
- 任务完成时机器人回复结果，执行过程中不显示进度。
- 单聊可以直接发文件和图片。群里机器人只收到文字和图文混排消息：图片请和文字一起发；文件请先放进项目目录，或改在单聊里发。
- 可要求助手把项目内的文件和图片发回当前会话，大小以企业微信限制为准，不需要另装企业微信 CLI。
- `/help` 查看命令，`/status` 看状态，`/stop` 停止任务；在群里，命令同样需要 @机器人。撤回消息不等于停止，请用 `/stop`。
- 目前不提供群历史查询、消息编辑、撤回或表情回应。

## 无法连接时

- 扫码创建失败：重试，或展开手动填写，使用已有机器人的凭据。
- 超过 10 分钟没收到消息：重新开始一次接入，在等待期间再给机器人发一句话。
- 核对机器人采用 API 长连接模式，凭据是否正确，且没有其他实例占用。
- 如果提示配置已保存但连接未启动，检查控制台连接状态，必要时重新启动 App 服务。
- 发送结果不明时不要自动重复发送，以免会话里收到重复内容。
