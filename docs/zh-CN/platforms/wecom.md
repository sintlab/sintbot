# 接入企业微信

[English](../../platforms/wecom.md) · 简体中文

使用企业微信「智能机器人 → API 模式 → 长连接」，任务在你的 Mac 上执行，无需公网回调地址。普通群 webhook 机器人不能用于接收任务。

## 1. 创建机器人

在企业微信电脑端进入「工作台 → 智能机器人 → 创建 → 手动创建」，选择「API 模式创建」，连接方式选「使用长连接」。保存 Bot ID 和 Secret。企业的创建权限由管理员设置；没有入口时先核对客户端版本和组织权限。

同一个机器人只由一台 SintBot 实例连接。测试时使用独立机器人，避免挤掉已有连接。

## 2. 在 SintBot 连接

首次打开 App：填写项目和执行器，在「聊天平台」选择「企业微信」，填写 Bot ID 和 Secret，点击「连接企业微信」。

已经在用飞书或本机对话：进入控制台「设置 → 添加企业微信」，填写凭据、已有项目目录和执行器，点击「连接并绑定项目」。原飞书连接、项目和历史保留。密钥只在本机填写，不发送到群里。

## 3. 绑定群并发送任务

在企业微信中建立或选择内部群，添加机器人。在 SintBot 显示等待群消息时，去目标群 @机器人 发送「连接」。SintBot 识别该群并绑定所选项目，不需要复制群 ID。第一条连接消息用于绑定；完成后重新 @机器人 发送实际任务，例如「读取 README 第一行，只回复这一行」。

保持 Mac 在线和 SintBot 服务运行。关闭窗口与停止后台服务是不同操作。

## 日常使用

- 群任务需要 @机器人；图片或文件可随任务发送。
- 可要求助手把项目内文件、图片发送到当前群，不需要另装企业微信 CLI。
- 发送文件上限为 50 MiB；平台可能对具体媒体类型另有限制。
- `/help` 查看命令，`/status` 看状态，`/stop` 停止任务；命令同样需要 @机器人。
- 历史查询、消息编辑/撤回、表情回应未接入。不要用撤回消息代替停止命令。

## 无法连接时

- 核对机器人采用 API 长连接模式，凭据是否正确，且没有其他实例占用。
- 等待群消息超时：确认机器人已加入目标群，在本轮接入等待期间重新 @它。
- 接入失败可取消或重试；如果提示配置已保存但连接未启动，检查控制台连接状态，必要时重新启动 App 服务。
- 发送结果未确认时不要自动重发，以免群里收到重复内容。
